# SPI Communication using Verilog HDL
## SPI Master-Slave communication system designed and verified using Verilog HDL and Vivado simulation.

Verilog HDL    Xilinx Vivado 2024.1    RTL Simulation Completed    MIT License

## Overview

This project implements an SPI (Serial Peripheral Interface)
Master-Slave communication system using Verilog HDL.

The design consists of an SPI Master, SPI Slave, Clock Divider,
and a Top-Level module that integrates all the components.

The RTL design was developed and verified using Xilinx Vivado 2024.1
through behavioral/RTL simulation and waveform analysis. This project
helps in understanding the SPI protocol and provides hands-on experience
in RTL design, FSM, clock division, testbench development and synthesis
analysis.


## Objectives

• Understand the working principle of the SPI protocol.
• Design an SPI Master using Verilog HDL.
• Design an SPI Slave using Verilog HDL.
• Implement clock division for SPI clock generation.
• Integrate the Master and Slave using a Top-Level module.
• Implement control logic using a Finite State Machine (FSM).
• Develop Verilog testbenches for functional verification.
• Perform RTL simulation using Xilinx Vivado.
• Analyze SPI communication signals using waveforms.
• Examine the synthesized RTL structure of the design.


## About SPI

SPI (Serial Peripheral Interface) is a synchronous serial communication
protocol used to exchange data between a controller and peripheral devices.
It uses four main signals:

Signal    Full Form                 Description

SCLK      Serial Clock              Clock generated by the Master
MOSI      Master Out Slave In       Data from Master to Slave
MISO      Master In Slave Out       Data from Slave to Master
CS        Chip Select               Selects / enables the Slave

SPI is widely used in microcontrollers, sensors, memory devices, displays,
ADC/DACs and other peripherals.


## System Architecture

The SPI system follows a Master-Slave architecture. The Top-Level module
connects the Master and Slave. The Clock Divider generates the SPI clock
from the system clock.

## Project Modules

### SPI Master
• Initiates the communication transaction.
• Controls Chip Select and SPI clock.
• Sends data through MOSI and receives data through MISO.
• Manages the transfer process using control logic.
  File:
  src/spi_master.v

### SPI Slave
• Responds when selected by the Master.
• Receives data through MOSI.
• Transmits data through MISO.
• Operates synchronously with the SPI clock.
  File:
  src/spi_slave.v

 ### Clock Divider
• Generates the required SPI clock from the system clock.
• Allows the SPI clock to run at a suitable frequency.
  File:
  src/clock_divider.v

 ###Top-Level Module
• Integrates the Master, Slave and clock logic.
• Provides the overall connection between modules.
• Exposes required input/output signals for simulation.
  File:
  src/spi_main.v
